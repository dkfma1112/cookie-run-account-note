현재 주력

감초 임시 이터널슈가덱

30레벨 중심 · 완전 자동 연습 약 8,500만 · 현재 바로 사용 가능

운영 방향

  • 아레나보다 토벌전·스토리·일반 PvE 우선
  • 감초 토벌을 첫 주력으로 운영
  • 현재 감초 임시 이터널슈가덱 유지 → 조건 충족 후 바람궁수덱 전환
  • 용은 쉐도우밀크 전용 파츠를 갖춘 뒤 진행
  • 기계신은 세팅 의존도가 높아 가장 나중에 준비
  • 스토리 기본형: 천년나무(획득 시) / 어둠마녀 / 시간지기 / 미스틱플라워 / 상황별 교체 1자리

육성 우선순위

  1. 이터널슈가 — 용·감초 토벌 양쪽에서 활용되는 최우선 투자
  2. 어둠마녀 — 스토리와 일반 PvE 범용 핵심 딜러
  3. 시간지기 — 스토리와 각종 PvE 범용 핵심
  4. 미스틱플라워 — 스토리 안정성을 담당하는 회복 쿠키
  5. 쉐도우밀크 — 용 토벌 핵심. 폼폼도우·푸른주스·블랙사파이어·캔디애플과 함께 육성
  6. 천년나무 — 확보 시 범용 전열·생존축으로 우선 육성
  7. 지하명왕 — 필요한 PvE 구간에서 막히면 순서를 앞당김
  8. 바람궁수 — 전환 조건을 갖춘 뒤 투자
  9. 사일런트솔트·세인트릴리·설탕백조·타임쉐도우 — PvP 성향이 강해 현재는 후순위
지하명왕 뽑기 판단

운명의 쿠키커터를 이미 210회 사용했다면, 추가 90개를 무료로 확보할 수 있을 때 300회 천장을 완성해 지하명왕을 확보한다. 현금 결제나 중요한 한정 재화를 과하게 써야 한다면 중단한다.

획득 후에도 천년나무를 먼저 확보·육성하고, 지하명왕은 특정 PvE 구간에서 필요할 때 순서를 앞당긴다.

토벌 육성 주의

토벌은 고등급 쿠키 한 명만 키워서는 완성되지 않는다. 이터널슈가·쉐도우밀크·바람궁수와 함께 각 덱의 에픽·스페셜 파츠, 보물, 마법사탕, 잼스톤을 맞춘다.

설탕백조

보유 확인, PvP 비중이 높아 후순위. 임시 권장: 라즈베리 5 / 라즈베리 타르트가 없으면 초콜릿칩 → 애플젤리 → 아몬드 순으로 대체 / 달콤 비스킷은 쿨타임 위주. 실제 레벨과 장착 여부는 확인 필요.

현재 맞춘 감초 임시덱

조합 포레누아 / 이터널슈가 / 블루파이 / 웨딩케이크 / 트위즐젤리

최종 목표덱

블루파이 / 바람궁수 / 슈크림 / 생크림담비 / 멜로우버니

육성 상태

  • 이터널슈가 80/80
  • 블루파이·포레누아·웨딩케이크·트위즐젤리 우선 30레벨
  • 스킬 가루가 부족해 전원 스킬 30이 아닐 수 있음. 마법형 가루는 블루파이 우선

토핑·타르트

  • 이터널슈가: 라즈베리 2 + 애플젤리 3 / 라즈베리 타르트
  • 포레누아: 라즈베리 2 + 애플젤리 3 / 라즈베리 타르트가 있으면 사용
  • 블루파이: 애플젤리 4 + 캐러멜 1 / 레전더리 캐러멜 타르트
  • 웨딩케이크: 애플젤리 3 + 초콜릿칩 2 / 초콜릿칩 타르트
  • 트위즐젤리: 애플젤리 3 + 초콜릿칩 2 / 초콜릿칩 타르트
  • 임시 토핑은 대체로 +6까지만 강화

비스킷

  • 이터널슈가: 폭발형, 독 속성 피해 증가 목표. 현재 공격력 9% 임시
  • 포레누아: 돌격형, 공격속도·치명타 우선. 없으면 공격력
  • 블루파이: 마법형, 전기 속성 피해 증가 우선. 없으면 공격속도·치명타·공격력
  • 웨딩케이크: 마법형, 쿨타임 우선
  • 트위즐젤리: 사격형, 쿨타임 우선
  • 모두 임시 단계이므로 옵션 재설정·세공 보류

보물

무공비급 / 별빛 호루라기 / 젤리시계. 마법 망토가 없어 젤리시계로 대체하며, 둘이면 쿨타임 감소가 높은 쪽 사용.

시험 결과

완전 자동 연습전 약 8,500만 피해 · 감초 체력 26% → 4%. 현재는 전원 레벨을 무리하게 올리지 않고 이 덱을 유지하며 부족한 쿠키만 보강.
바람궁수 감초덱 준비 현황
  • 잼스톤은 제작해도 되는 장기 투자. 실제 제작 및 강화 단계는 확인 필요
  • 임시 장비: 생명돋움 라즈베리 5
  • 정식 타르트: 라즈베리. 라즈베리·초콜릿칩이 없으면 캐러멜을 임시 사용
  • 캐러멜 타르트를 써도 토핑은 라즈베리 5 유지
  • 목표: 잼스톤 포함 총 공격속도 약 32.2%, 바람 속성 피해 비스킷
  • 정식 조합: 블루파이 / 바람궁수 / 슈크림 / 생크림담비 / 멜로우버니
  • 전환 조건: 바람궁수 초월, 잼스톤 약 15강, 슈크림 마법사탕 약 20강, 담비·멜버 확보
  • 현재는 이터널슈가 임시덱을 유지하고 천천히 준비

독피증이 가장 높은 비스킷은 블랙사파이어에게 장착. 폼폼도우·쉐도우밀크·블랙사파이어의 치명타 확률이 67% 이상이면 라즈베리 1개 장착.

스킬 순서 쉐도우밀크 예약 → 푸른주스 → 폼폼도우 → 블랙사파이어 → 푸른주스 → 캔디애플 → 이후 쿨타임에 맞춰 사용. 블랙사파이어도 예약.

기계신 · 바요덱

보물 시계(곰젤리) / 무공비급 / 호루라기(훈돈)

세팅 · 토핑 / 타르트 / 비스킷

  • 프릴해파리: 라즈베리 4 + 초코칩 1 / 초코칩 / 쿨타임 또는 물피증
  • 바다요정: 라즈베리 2 + 초코칩 3 / 라즈베리 / 물피증
  • 탄산수: 라즈베리 3 + 초코칩 2 / 라즈베리 / 물피증 또는 쿨타임
  • 멘톨: 라즈베리 / 라즈베리 / 물피증
  • 생크림담비: 라즈베리 1 + 초코칩 4 / 라즈베리 / 쿨타임
멘톨의 공격력을 가장 높게 세팅하고, 물피증이 가장 높은 비스킷도 멘톨에게 장착.

스킬 순서 생크림담비 예약 → 바다요정 → 탄산수 → 프릴해파리 → 멘톨 자동 발동 → 이후 쿨타임에 맞춰 사용. 멘톨도 예약.

빠른 선택 요약

  • 감초: 250억 이하에서는 이슈덱, 250억 이상 및 조건 충족 시 바궁덱
  • 기계신: 바요덱 사용

표기는 토핑 / 타르트 / 비스킷 순서이며, 원본에서 비어 있던 내용은 임의로 보완하지 않았습니다.

감초 임시덱부터 완성

이터널슈가와 웨딩케이크를 이미 보유해 감초 임시덱을 한 팀으로 완성하기 쉬워졌다.

  1. 블루파이 — 마일리지 1순위. 최종 바람궁수덱에도 유지
  2. 포레누아 — 마일리지 2순위. 감초 임시덱 전열
  3. 트위즐젤리 — 마일리지 3순위. 감초 임시덱 완성

육성 순서 감초 이터널슈가덱 완성 → 용 쉐도우밀크덱 → 생크림담비·멜로우버니 획득 후 감초 바람궁수덱 전환 → 기계신

임시 조합 포레누아 / 이터널슈가 / 블루파이 / 웨딩케이크 / 트위즐젤리

최종 목표덱

블루파이 / 바람궁수 / 슈크림 / 생크림담비 / 멜로우버니

임시 세팅 · 토핑 / 타르트 / 비스킷

  • 포레누아: 라즈베리 2 + 애플젤리 3 / 라즈베리 타르트 / 공격속도·치명타 우선
  • 이터널슈가: 라즈베리 2 + 애플젤리 3 / 라즈베리 타르트 / 독 속성 피해 증가
  • 블루파이: 애플젤리 4 + 캐러멜 1 / 캐러멜 타르트 / 전기 속성 피해 증가
  • 웨딩케이크: 애플젤리 3 + 초콜릿칩 2 / 초콜릿칩 타르트 / 쿨타임
  • 트위즐젤리: 애플젤리 3 + 초콜릿칩 2 / 초콜릿칩 타르트 / 쿨타임
블루파이는 최종덱에도 남으므로 가장 먼저 투자한다. 나머지 임시 파츠는 과투자하지 않는다.

최종 목표덱

폼폼도우 / 쉐도우밀크 / 푸른주스 / 블랙사파이어 / 캔디애플

마일리지 2명만 구매할 경우 아포가토를 임시 사용하고, 이후 푸른주스로 교체한다.

임시 세팅 · 토핑 / 타르트 / 비스킷

  • 폼폼도우: 애플젤리 5 / 애플젤리 타르트 / 독 속성 피해 증가
  • 쉐도우밀크: 애플젤리 5 / 애플젤리 타르트 / 쿨타임
  • 아포가토: 초콜릿칩 2 + 애플젤리 3 / 초콜릿칩 타르트 / 독 속성 피해 증가 또는 쿨타임
  • 블랙사파이어: 애플젤리 5 / 애플젤리 타르트 / 독 속성 피해 증가
  • 캔디애플: 애플젤리 2 + 캐러멜 2 + 아몬드 1 / 아몬드 타르트 / 피해감소 2 + 공격속도 2
3순위 · 기계신 임시덱

현재 조합 프릴해파리 / 바다요정 / 샤벳상어 / 멘톨 / 크림유니콘

최종 목표덱

프릴해파리 / 바다요정 / 탄산수 / 멘톨 / 생크림담비

생크림담비를 얻으면 크림유니콘과 교체하고, 탄산수를 얻으면 샤벳상어와 교체한다.

찬란한 영웅들의 신전 사용법

위쪽 영웅 5명 중 가장 낮은 레벨이 신전의 기준 레벨이 된다. 다섯 명을 고르게 실제 육성하고, 아래 슬롯에는 별사탕을 아끼고 싶은 토벌 파츠를 넣는다.

당근 계정 영웅 후보

이터널슈가 / 어둠마녀 / 시간지기 / 미스틱플라워 / 쉐도우밀크

신전 슬롯 우선 후보

포레누아 / 블루파이 / 웨딩케이크 / 트위즐젤리 / 이후 새로 얻은 토벌용 에픽

스킬 레벨 축복

  • 같은 유형에서 스킬 레벨이 높은 쿠키 3명 중 가장 낮은 수치가 해당 유형의 기준이 된다.
  • 예: 마법형 스킬이 80 / 75 / 70이면 신전에 등록한 마법형 쿠키의 스킬이 70까지 보정된다.
  • 자주 사용하는 유형은 스킬 높은 쿠키 3명을 먼저 만든다.

주의사항

  • 슬롯에서 빼면 쿠키는 실제 레벨과 스킬 레벨로 돌아간다.
  • 쿠키를 뺀 슬롯은 24시간 동안 다시 사용할 수 없다.
  • 승급·초월, 토핑, 타르트, 비스킷, 마법사탕·잼스톤은 복사되지 않는다.
  • 일부 임무는 신전 보정이 아닌 실제 레벨을 기준으로 판단한다.
주력 5명에게 별사탕을 집중하고, 임시 토벌 파츠는 신전으로 시험하는 용도다. 2026년 8월 기준 슬롯은 최대 40칸이며 스킬 축복은 유형별 3명을 기준으로 한다.

랜드마크 구매·강화 순서

현재 보유 똑딱쿠키 시계탑, 꿈꾸는 젤리라이언 조각상, 연회장에 남겨진 케이크타워, 영원한 영웅의 기념상, 커피머신, 쿠키 분석기, 장엄한 곰젤리인형

다음 구매 순서

  1. 혼돈이 휘몰아치는 마왕성 — 모든 쿠키 피해감소. 토벌·스토리·아레나 공용
  2. 으스스한 귀신의 집 — 치명타 확률 증가
  3. 치명타 피해 증가 랜드마크 — 토벌 피해량 보강
  4. 이슬 담긴 유리정원 — 모든 쿠키 체력 증가
  5. 영원한 겨울의 스노우 글로브 — 모든 쿠키 방어력 증가
  6. 고기젤리 생산 랜드마크 — 스토리·비스트이스트 반복 플레이용
  7. 대관람차·뽑기 머신 — 영혼석 생산, 전투 랜드마크 이후

보유 랜드마크 강화 순서

  1. 똑딱쿠키 시계탑
  2. 꿈꾸는 젤리라이언 조각상
  3. 연회장에 남겨진 케이크타워
  4. 영원한 영웅의 기념상
  5. 커피머신·쿠키 분석기·장엄한 곰젤리인형
케이크타워는 별도 재료인 케이크 파편을 사용하므로 파편이 생기면 계속 강화한다. 영원한 영웅의 기념상은 에인션트 쿠키에게만 적용되므로 범용 전투 랜드마크를 먼저 올린다.
